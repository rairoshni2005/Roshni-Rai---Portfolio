## Overview

This is a **React single-page interactive portfolio** with dedicated project-detail routes.

Rather than functioning as a traditional static resume, the website is designed as an interactive personal system that combines professional work, projects, achievements, leadership, technical skills, and experimental UI interactions.

### The experience includes

- Cinematic hero section with a 3D Spline scene
- Draggable headline and interactive hero elements
- Rotating professional roles
- Audio-reactive visual atmosphere
- About, skills, experience, education, leadership, achievements, hobbies, projects, and contact sections
- Scroll-driven project and case-study experiences
- Interactive project detail pages
- Floating responsive navigation dock
- Keyboard-accessible Command Center
- Achievement and easter-egg system
- Resume decryption experience
- Interactive signature pad
- Terminal-style contact interface
- Custom cursor and atmospheric effects
- Night Vision mode
- Magnetic interactions
- Responsive layouts for desktop, tablet, and mobile

# Interactive Systems

## Command Center

The interactive system terminal can be opened using:

* `Cmd + K` on macOS
* `Ctrl + K` on Windows/Linux
* Terminal button in the floating navigation dock

The Command Center provides:

* Command search
* System-log search
* Night Vision
* Resume/CV decryption
* Achievement Archive
* Accent theme switching

### Keyboard Shortcuts

| Key   | Action                   |
| ----- | ------------------------ |
| `N`   | Toggle Night Vision      |
| `D`   | Open CV Decryption       |
| `A`   | Open Achievement Archive |
| `Esc` | Close Command Center     |

---

## Achievement System

Interactive actions unlock achievements and display animated notifications.

Achievement progress is stored locally in the browser.

| ID                | Achievement         | Trigger                                      |
| ----------------- | ------------------- | -------------------------------------------- |
| `FOUND_CMD_K`     | System Breaker      | Open the Command Center                      |
| `ALTERED_REALITY` | Reality Glitch      | Change the accent theme                      |
| `HERO_DISTURBED`  | Annoyance Expert    | Interact with the hero headline repeatedly   |
| `NEURAL_ACCESS`   | Mind Hunter         | Activate the Neural Link interaction         |
| `LONG_STAY`       | Dedicated Visitor   | Remain on the page for 60 seconds            |
| `FINAL_MASTER`    | The Master Explorer | Unlock the first five non-final achievements |

The Achievement Archive displays both unlocked and locked achievements.

---

## Resume Decryption

The Hero `Access CV` button and Command Center `D` command open an animated resume-decryption experience.

The sequence includes:

1. Classified document state
2. Decryption progress animation
3. Decryption completion state
4. Browser download of the resume

The current resume file is:

public/Roshni Rai - Resume.pdf

## Signature Pad

The signature modal allows users to draw a signature using a mouse or trackpad.

The signature is:

* Stored as a data URL in `localStorage`
* Restored when the modal is opened again
* Sent to the footer using the `signature-updated` event

# Event-Driven Communication

Global systems communicate using browser `CustomEvent`s.

| Event                 | Producer / Consumer                         | Purpose                   |
| --------------------- | ------------------------------------------- | ------------------------- |
| `open-command-center` | Navbar → CommandCenter                      | Open terminal             |
| `toggle-night-vision` | CommandCenter → App                         | Toggle Night Vision       |
| `open-vault`          | CommandCenter → App                         | Open Achievement Archive  |
| `open-decryption`     | Hero/CommandCenter → App                    | Open CV modal             |
| `unlock-achievement`  | Interactive systems → AchievementSystem/App | Record achievements       |
| `signature-updated`   | SignaturePad → Footer                       | Refresh signature         |
| `change-vibe`         | SoundMixer → AmbientSound                   | Change sound profile      |
| `audio-pulse`         | AmbientSound → Hero                         | Drive hero aura animation |

Example:

window.dispatchEvent(
  new CustomEvent('open-vault')
);

The application uses browser `localStorage` for selected interactive features.

| Key                             | Value                                  |
| ------------------------------- | -------------------------------------- |
| `roshni_achievements`           | JSON array of unlocked achievement IDs |
| `roshni_signature`              | Saved signature canvas data URL        |
| `roshni_achievements_signature` | Optional footer fallback key           |

# Troubleshooting

## Blank Page

Run:

npm run build

Check the browser console for missing assets or runtime errors.

Then test:

npm run preview

---

## Resume Download Fails

Confirm the file exists at:

public/Roshni Rai - Resume.pdf

The path is case- and space-sensitive.

---

## Project Detail Refresh Returns 404

Configure the hosting platform's SPA fallback to rewrite requests to:

index.html

---

## Images Do Not Load

Confirm the image exists under:

public/images/

Use root-relative paths such as:

/images/profile.png

rather than filesystem paths.

---

## Command Center Does Not Open

Try:

Cmd + K

on macOS or:

Ctrl + K

on Windows/Linux.

You can also click the terminal icon in the floating navigation dock.

If it still does not work, inspect the browser console and check whether a browser extension has claimed the keyboard shortcut.

---

## Contact Submission Fails

The contact terminal depends on a browser request to FormSubmit.

Check:

* Browser network panel
* Third-party request blocking
* FormSubmit availability
* Recipient configuration in `TerminalContact.jsx`

---

## Signature Is Not Visible

Save a new signature and confirm browser storage is enabled.

Check:

roshni_signature

in browser local storage.

Private browsing settings may restrict local storage.

---

## Cursor Is Hidden

The custom cursor behavior is intentional on fine-pointer devices.

To restore the native cursor, inspect the fine-pointer cursor rules in:

src/index.css

---

## Lint or Build Issues

Run the commands separately:

npm run lint

then:

npm run build

Large bundle warnings may occur because the portfolio includes Spline, particle, physics, and animation dependencies. These warnings do not necessarily indicate a failed build.
